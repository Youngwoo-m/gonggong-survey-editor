## ㉢ 지켜야 할 것

- 문체 규칙은 **변경 사유에만** 적용하고 조문에는 적용하지 아니한다. 개조식,
  `~음/~임/~함/~필요함`, 가운데점(`·`) 금지(아래아 `ㆍ`는 허용), 화살표(`→`) 금지,
  모든 문장 끝 마침표, 마침표 뒤 줄바꿈.
- 다만 코드의 상태 상수는 이미 `"이동·수정"` 로 `·` 를 쓰고 있으므로 그 안에서는
  일관을 지킨다.
- 구어체 대신 규정 문체, 명사형. 「얼개」 대신 「구조」.
- `data/loc29.json`, `data/loc30.json`, `data/loc31.json`, `data/objects/loc30/`,
  `data/objects/loc31/` 는 **절대 저장소에 올리지 아니한다**(ISO 저작권). 푸시
  전마다 `.gitignore` 로 막혀 있는지 확인한다.
- 없는 표준 번호를 조문에 적지 아니한다. 표 XML 이 이미 있는 별표 56개에는 본문
  글을 넣지 아니한다.
- 자료 파일을 고쳐도 앱은 IndexedDB 자동저장을 읽으므로 바로 보이지 아니한다.
  `[data-cmd="reload"]` 를 눌러야 하는데 `confirm()` 을 쓰므로, 미리보기에서
  확인할 때는 `window.confirm = () => true` 로 덮고 누른다.
- 자료를 손으로 고칠 때 조 번호는 `scripts/renumlib.py`(= `js/core/model.js` 의
  `renumber()` 이식)로 다시 매긴다.
- Bash heredoc 이 역슬래시를 먹으므로, 정규식이 든 파이썬은 Write 도구로 파일에
  적어 돌린다.
