# 공공측량 성과심사 규정 개정 편집기

「측량성과 심사수탁기관의 심사업무 및 지정절차 등에 관한 규정」
(국토지리정보원고시 제2025-2091호, 5장 43조 · 별표 12)을 고치는 편집기입니다.

- 주소 — `/review/` (윗 폴더의 작업규정 편집기는 `/`)
- 로컬 실행 — 윗 폴더의 `실행.성과심사.bat`, 또는 `python serve.py 8766 review/`

이 폴더에는 **화면 파일(`index.html`) 하나만** 있습니다.
프로그램(`../js`)과 규정 데이터(`../data`)는 작업규정 편집기와 한 벌을 함께 씁니다.
`<base href="../">` 로 윗 폴더를 가리키고,
`<meta name="app-profile" content="review">` 로 “성과심사 규정을 고치는 편집기”임을 알립니다.

무엇이 다른지는 `../js/core/appconfig.js` 의 `review` 프로파일 한 곳에 모여 있습니다.

| | 값 |
|---|---|
| 개정 대상 | 측량성과 심사수탁기관의 심사업무 및 지정절차 등에 관한 규정 (`data/reg29.json`) |
| 시작 버전 | v1. 개정안 초안 (`data/draft_simsa.json` — `python scripts/gendraft_simsa.py` 로 다시 만듭니다) |
| ② 창 차례 | 성과심사 관련규정 12종 → 공공측량 작업규정 → 상위 법령 → … |
| 최상위 계층 | 장 (이 규정에는 편이 없습니다) |
| 부르는 말 | 개정안 |

기능·단축키·저장 방식은 모두 같습니다. 자세한 설명은 [../README.md](../README.md) 를 보십시오.
